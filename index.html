A TYPING SYSTEM BASED ON THE BRAILLE GRID.

Braille is a tactile writing system. Each character is made of six dots arranged in a 2×3 grid, raised on paper so it can be read by touch.


HOVER THE CELL TO SEE THE DOTS.

A screen can’t have raised dots, so I replaced each dot with a filled black square. The 2×3 grid stays the same — the position of the squares is what tells you which letter it is.
